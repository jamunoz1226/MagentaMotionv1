# MagentaMotion

Performance tracker app with OCR-powered metric extraction.

Getting started
- Install: `npm install`
- Dev: `npm run dev`
- Build: `npm run build`

OCR extraction
- Upload a report image in the Upload screen.
- The OCR pipeline parses key metrics and the modal lets you review/edit.

Notes
- Built with React, TypeScript, and Vite.
